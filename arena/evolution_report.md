# Proving Grounds: subclass evolution

Ascendant and Corrupted branches from `evolution.py`, unlocked at 6th level. Every four-hero party containing the subclass (120 parties) against the four party encounters at levels 7, 10, 15, 12 fights each, once as written and once with that one hero evolved (same seeds). Corrupted powers per fight: **1**. Generated by `uv run arena/evolve.py`.

**How to read it**

- **Uplift** is the change in the party's win rate, in percentage points, from evolving that one hero. Branches in the same pillar should land close together.
- **Fires** is how often the branch feature triggered per fight. Near 0 means the feature rarely comes up in these encounters, so its uplift says little.
- Noise: each uplift averages about 5,760 fights per level; treat differences under about 1.5 points as noise.
